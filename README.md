# Autonomous Agents 🚀

A multi-agent AI system designed to explore problems, generate original ideas, analyze them, challenge them, and select the most promising opportunities.

The system uses **CrewAI** to orchestrate specialized AI agents and exposes the workflow through a **FastAPI** API.

## 🧠 How it works

The system uses a sequential pipeline of specialized agents:

```text
Research
   ↓
Invention
   ↓
Scientific Analysis
   ↓
Adversarial Criticism
   ↓
Final Judgment
   ↓
Winning Idea + MVP
```

### 1. 🌍 Global Researcher

Investigates a given topic and identifies:

* Emerging technologies
* Problems and inefficiencies
* Market gaps
* Changing behaviors
* Potential opportunities

### 2. 💡 Radical Inventor

Uses the research to generate original product concepts and explores unusual combinations of technologies, markets and human needs.

### 3. 🔬 Scientific Thinker

Analyzes the ideas using first-principles reasoning and identifies technical mechanisms, assumptions and hidden opportunities.

### 4. 🛡️ Adversarial Critic

Challenges the proposed ideas by examining:

* Competition
* Technical feasibility
* User demand
* Economics
* Monetization
* Scalability
* Risks and failure modes

### 5. ⚖️ Innovation Judge

Scores and ranks the strongest concepts according to:

* Originality
* Problem severity
* Market size
* Feasibility
* Monetization
* Defensibility
* Scalability
* Growth potential

The system then selects a final winning concept and proposes a realistic MVP.

## 🤖 Multiple LLM providers

The project supports multiple LLM providers through a centralized configuration:

```text
Groq
OpenRouter
Google Gemini
```

Each agent can use a different model, allowing the system to combine different models for different tasks.

## 🚀 API

Start the FastAPI server:

```bash
uvicorn main:app --reload
```

### Health check

```http
GET /health
```

Returns:

```json
{
  "status": "healthy"
}
```

### Run the agents

```http
POST /run
```

Example request:

```json
{
  "objective": "Find a revolutionary solution for online education"
}
```

The API returns the objective and the result generated by the agent crew.

## 🔐 Configuration

API keys are provided through environment variables.

The project keeps API credentials outside the source code and can also be configured through GitHub Secrets for automated workflows.

Example:

```text
G=
G1=
G2=
OP2=
OP3=
GEM=
```

See `.env.example` for the expected configuration.

## 🤖 GitHub Actions

The project includes GitHub Actions workflows for:

* Running the agent system automatically
* Running tests
* Preserving generated results as workflow artifacts

An objective can be supplied through the `OBJECTIVE` environment variable.

## 🎯 Project goal

The goal of this project is to experiment with **autonomous multi-agent systems** capable of going beyond simple text generation by dividing complex reasoning into specialized roles.

It is also an exploration of how different LLM providers can be combined into a single AI workflow.
